# Bay Slam Home Screen icon

Original asset generated with the built-in imagegen tool, then exported with macOS `sips` at the sizes required by the game. Full-color, opaque PNG; rounded corners are applied by iOS rather than baked into the art.

- `icon-1024.png`: reusable design export.
- `icon-512.png`, `icon-192.png`: web app manifest icons.
- `../apple-touch-icon.png`: 180px iPhone icon.
- `apple-touch-icon-167.png`, `apple-touch-icon-152.png`: iPad variants.
- `favicon-32.png`: browser tab icon.

The larger original generation is retained locally as `icon-master.png` and excluded from Git and the offline download. No existing character art was replaced by this icon.

## Generation prompt

Use case: logo-brand. Create one production-ready square iOS Home Screen app icon for Sturgeon Bay Slam, a funny independent wrestling booking game set in a small Wisconsin community hall. Original cut-paper screenprinted sports-poster illustration, not a mockup. One bold cream-colored folding chair tilted dynamically across a chunky red impact starburst, with a small golden five-point wrestling star as a secondary accent. Deep ink navy (#102a40) full-bleed background, warm mustard yellow (#f0c65a), vermilion red (#e34f32), cream paper (#fff5dc). Strong dark outlines, simple large geometric paper shapes, slight handmade paper texture and offset printed edges. The chair should read unmistakably as a metal folding chair with its seat and back, not a ladder. A compact heroic emblem with energy and humorous backyard wrestling attitude. All important shapes fit within the central 72 percent of the square so the mark survives iOS rounded-corner masking. Bold silhouette readable at 60 pixels, minimal detail. No letters, no text, no words, no watermarks, no phones, no app-store presentation, no surrounding whitespace, no baked-in rounded corners, no transparency. Flat front-facing graphic asset, 1024 by 1024 square.
