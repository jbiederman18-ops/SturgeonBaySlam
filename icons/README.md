# Bay Slam Home Screen icon

The Rise to Supremacy icon is a full-bleed boxing window card: a red band with STURGEON BAY in Oswald, SLAM in Alfa Slab One with a red offset print on cream stock, and a blue band of three stars. The editable artwork is in `window-card-icon.svg` (the earlier Kayfabe artwork stays in `kayfabe-icon.svg`). Render it with the bundled fonts loaded Render it as an opaque square PNG and let the device apply its own icon mask.

- `icon-1024.png`: reusable design export.
- `icon-512.png`, `icon-192.png`: web app manifest icons.
- `../apple-touch-icon.png`: 180px iPhone icon.
- `apple-touch-icon-167.png`, `apple-touch-icon-152.png`: iPad variants.
- `favicon-32.png`: browser tab icon.
